## Featured projects

- **[ScaleSense](https://github.com/Cobby914/ScaleSense)** — CARLA/SUMO radar-camera simulation for testing roadside radar layouts, with synchronized multi-sensor capture and offline labeling (~87% oriented-bounding-box precision at ~3,000 returns/sec).
- **[TENA](https://github.com/Cobby914/TENA)** — Production React/Vite website and admin portal ([tenacares.org](https://tenacares.org)) with Express, PostgreSQL, and Firebase Auth. I lead a team of 5 developers.
- **[Celebrating Life Community Health Center](https://github.com/ctc-uci/clchc)** — Full-stack clinic platform (React, TypeScript, Node, PostgreSQL, Google OAuth) built with [Commit the Change](https://ctc-uci.com/), used daily by 14 staff.
- **[Personal website](https://github.com/Cobby914/Personal_Website)** — Portfolio at [colinkwon914.com](https://colinkwon914.com/), built with Next.js, React, Tailwind CSS, Zustand, and Radix UI.
- **[CanvasNotionSync](https://github.com/Cobby914/CanvasNotionSync)** — Python sync from Canvas LMS into Notion, with idempotent updates and GitHub Actions scheduling.
- **[Smart Stick](https://github.com/Cobby914/Smart-Stick)** — ESP32/Arduino assistive cane using ultrasonic and time-of-flight sensors, with AWS telemetry (~80% obstacle/elevation detection accuracy).
